3. 需要跟进什么

- 无需。服务正在运行，可按以下方式调用。

接口配置

  Base URL    ${LOCAL_API}
  Model       edge0-145b-nvfp4
  API key     任意占位值（本机服务未启用认证）
  Health      ${LOCAL_API}/health
  Models      ${LOCAL_API}/models

启动（PowerShell）

  powershell -NoProfile -ExecutionPolicy Bypass -File ${EDGE0_ROOT}\Start-Edge0.ps1

  启动后等待 /health 返回 loaded=true。该脚本发现已在运行时直接返回。

停止（PowerShell）

  powershell -NoProfile -ExecutionPolicy Bypass -File ${EDGE0_ROOT}\Stop-Edge0.ps1

终端连续对话

  ${EDGE0_ROOT}\repo\edge0-strata\.venv\Scripts\python.exe ${EDGE0_ROOT}\Chat-Edge0.py

  /new 开始新对话，/quit 退出客户端。退出客户端后模型服务继续运行。

Python OpenAI SDK 示例（在已安装 openai 的客户端环境执行）

  from openai import OpenAI
  client = OpenAI(base_url="${LOCAL_API}", api_key="local")
  response = client.chat.completions.create(
      model="edge0-145b-nvfp4",
      messages=[{"role": "user", "content": "你好，请用中文介绍一下你能做什么。"}],
      max_tokens=512,
      temperature=0.7,
      reasoning_effort="none",
  )
  print(response.choices[0].message.content)
